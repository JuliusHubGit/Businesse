## Preis-Spartipps

1. **Gebraucht kaufen:**
   - eBay Kleinanzeigen
   - Raspberry Pi oft günstig gebraucht
   - Achtung: Auf Vollständigkeit achten

2. **Bundle-Deals:**
   - Komplettsets oft günstiger
   - Black Friday / Cyber Monday

3. **Alternative Displays:**
   - Auch 5" oder 10" Displays möglich
   - Kleinere Displays = günstiger
   - HDMI-Anschluss ist wichtig!

4. **SD-Karte:**
   - Markenware kaufen (SanDisk, Samsung)
   - 16GB reicht für Basis-Installation
   - 32GB empfohlen für viele Bilder

5. **Netzteil:**
   - Offizielles Pi-Netzteil empfohlen
   - Oder anderes Qualitäts-Netzteil mit genug Ampere
   - Billiges Netzteil = Probleme!

## Kompatibilitäts-Check

✅ **Kompatibel:**
- Raspberry Pi Zero 2 W + 7" Display → Mini HDMI Kabel nötig
- Raspberry Pi 3 B/B+ + 7" Display → Standard HDMI Kabel
- Raspberry Pi 4 + 7" Display → Micro HDMI Kabel nötig

❌ **Nicht kompatibel:**
- Raspberry Pi Zero (ohne W) → Kein WLAN!
- Raspberry Pi 1 Model A/B → Zu langsam
