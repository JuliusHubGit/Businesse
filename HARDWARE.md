# Hardware Informationen

## Raspberry Pi 2 Model W

**Hinweis:** Es gibt kein offizielles "Raspberry Pi 2 W" Modell. Wahrscheinlich ist gemeint:
- **Raspberry Pi Zero W** oder
- **Raspberry Pi Zero 2 W** (empfohlen für dieses Projekt)

### Raspberry Pi Zero 2 W Spezifikationen
- **Prozessor:** Broadcom BCM2710A1, quad-core 64-bit SoC (ARM Cortex-A53 @ 1GHz)
- **RAM:** 512MB LPDDR2
- **WLAN:** 2.4GHz IEEE 802.11 b/g/n
- **Bluetooth:** Bluetooth 4.2, BLE
- **Video:** Mini HDMI-Anschluss
- **USB:** Micro USB OTG Port
- **GPIO:** 40-pin GPIO Header
- **Stromversorgung:** 5V über Micro USB
- **Empfohlene Stromversorgung:** 5V/2.5A Netzteil

## 7 Inch Raspberry Pi Display

### Produktbezeichnung
"7 Inch Raspberry Pi 4/3/2/B/B+/A+ Monitor 1024x600 IPS 5-Points Capacitive Touchscreen Drive Free HDMI Display For Win 7/8/10"

### Spezifikationen
- **Bildschirmgröße:** 7 Zoll
- **Auflösung:** 1024x600 Pixel
- **Display-Typ:** IPS (In-Plane Switching) für bessere Blickwinkel
- **Touchscreen:** 5-Punkt kapazitiver Touchscreen
- **Anschluss:** HDMI
- **Treiber:** Keine zusätzlichen Treiber erforderlich ("Drive Free")
- **Kompatibilität:** Raspberry Pi 4/3/2/B/B+/A+, Windows 7/8/10
- **Stromversorgung:** Über USB (meist vom Raspberry Pi)

### Verbindung mit Raspberry Pi Zero 2 W
1. **HDMI-Verbindung:** Mini HDMI zu HDMI Adapter/Kabel erforderlich
2. **Stromversorgung:** Display benötigt eigene USB-Stromversorgung
3. **Touchscreen:** USB-Kabel für Touch-Funktionalität (optional für dieses Projekt)

## Empfohlenes Zubehör

### Notwendig
- Raspberry Pi Zero 2 W
- 7" Display wie oben beschrieben
- microSD-Karte (mindestens 16GB, Class 10)
- Mini HDMI zu HDMI Kabel/Adapter
- 5V/2.5A USB-Netzteil für Raspberry Pi
- USB-Netzteil für Display (oder Y-Kabel)

### Optional
- Gehäuse für Raspberry Pi und Display
- Kühlkörper für Raspberry Pi
- USB-Tastatur und Maus (für Setup)
